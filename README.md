# roinamis

Create a dedicated email and SMS sign-up page for the fashion brand roinamis.

Purpose
This page exists only to collect emails and phone numbers from supporters before and between drops. No shopping, no product listings, no extra navigation. One clear action.

Brand Alignment
roinamis is rooted in culture, purpose, and quiet faith. The feeling should be calm, refined, and intentional. Nothing loud or flashy. Faith is present through mood and symbolism, not words.

Layout Structure
• Full-screen page
• Centered sign-up module
• Minimal copy
• Single call to action
• No header navigation
• No footer links beyond privacy/terms if required

Copy Direction
Short and restrained.
Invitational, not promotional.
Avoid hype language.

Example tone (do not overuse text):
“Stay close.”
“Be part of what’s coming.”
“Early access. Limited drops.”

Visual & Background Effects
Use a subtle, modern background effect that feels elevated and calm, not overwhelming.

Effect guidelines:
• Slow-moving grain, noise, or texture
• Soft light shifts or gradient movement
• Subtle parallax or depth, not distraction
• Earth-tone color palette
• Motion should feel meditative and intentional
• Avoid flashy animations, neon colors, or fast movement

The background effect should support the mood, not compete with the sign-up form.

Typography
Bold but clean headline
Simple, readable body text
Consistent with the roinamis brand typography

Form Elements
• Email input
• Optional phone number input for SMS
• Clear submit button
• Simple confirmation message after submission

Button Style
Solid, grounded color
No hover gimmicks
Confident and minimal

Photography (optional)
If imagery is used, keep it minimal and faded into the background.
Urban or studio-style imagery only.
Never distract from the form.

Overall Feel
Quiet confidence
Premium streetwear
Purpose-driven
Feels like an invitation, not an ad

Technical Notes
• Mobile-first design
• Fast load time
• Smooth but subtle animations
• Accessible contrast and readable text

Do not include product pricing, lookbooks, shopping features, or long explanations.
This page is only for collecting emails and SMS sign-ups for the roinamis community.
